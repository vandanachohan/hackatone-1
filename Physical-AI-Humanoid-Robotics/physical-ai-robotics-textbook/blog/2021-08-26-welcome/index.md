## 📁 How This Blog Works
Simply add Markdown (`.md` / `.mdx`) files to the `blog` directory, and Docusaurus will automatically generate blog pages.

### 🧑‍💻 Add authors
You can edit or add authors in:
```
authors.yml
```

### 🗓 Blog dates
Dates are extracted from filenames, for example:
- `2025-01-10-introduction.md`
- `2025-01-10-introduction/index.md`

### 🖼 Add images
Blog folders support images placed beside the Markdown file.

![Humanoid Robot](./humanoid-robot-banner.jpeg)

## 🏷 Tags
You can tag your posts to organize content — tags like *robotics*, *AI*, *motion-control*, *ROS*, etc.

If you do not want to use a blog, you can disable it in:
```
docusaurus.config.js
```
with:
```
blog: false
