# Project Master Specification (claude.md)

# Physical AI and Humanoid Robotics: Foundations, Engineering, and Intelligent Systems

This file defines the authoritative, single-source specification for the entire Docusaurus-based textbook on Physical AI and Humanoid Robotics.
All Spec-Kit Plus slash-commands, Claude Code, MCP server integrations, and code generation must rely solely on the requirements in this file and the governing `.specify/constitution.md`.

The system must automatically produce the complete project:

• `/sp.constitution`
• `/sp.specify`
• `/sp.plan`
• `/sp.tasks`
• `/sp.implement`

No additional instructions from the user should be required.

The final output must be a ready-to-deploy documentation system and codebase.

---

## 1. Core Objective

Generate a complete, functional, production-grade educational platform for the textbook "Physical AI and Humanoid Robotics" including:

• A Docusaurus v3 documentation site
• All textbook chapters in MDX
• Integrated RAG chatbot
• Personalization features
• Urdu translation support
• Authentication
• Sub-agents and reusable AI tools
• Backend (FastAPI + Neon + Qdrant)
• Frontend integration using OpenAI Agents / ChatKit

The full system must scaffold automatically using Spec-Kit Plus and Claude Code.

---

## 2. System Behavior

Spec-Kit Plus must:

1. Read this file plus `.specify/constitution.md`.
2. Generate a complete Docusaurus project.
3. Auto-create all directories, files, MDX pages, sidebars, routing.
4. Scaffold the backend server and integrate API endpoints.
5. Produce all plans, tasks, diagrams, and implementation structure.
6. Generate a fully connected MCP server supporting:

   * RAG indexing
   * Chatbot responses
   * Personalized rewrites
   * Urdu translation
   * Sub-agent invocation
7. Output a GitHub-ready repository with `deploy.yml` for GitHub Pages.

The pipeline must be fully automatic after the initial slash command.

---

## 3. Functional Requirements

### 3.1 Docusaurus Book Generation

Claude Code must produce:

• Docusaurus v3 project using Spec-Kit Plus template
• Autogenerated sidebar
• All chapters and subchapters
• MDX placeholders for content
• “Personalize Content” button
• “Translate to Urdu” button
• Integrated chatbot widget

---

### 3.2 RAG Chatbot Integration

Backend:
• FastAPI server
• Neon Serverless Postgres (user profiles, metadata)
• Qdrant Cloud (vector embeddings)
• OpenAI embeddings + ChatCompletions API
• Text chunking and citation-aware retrieval system

Frontend:
• Floating chatbot widget
• Mode A: Ask questions about the entire book
• Mode B: Ask questions restricted to user-selected text
• Source citations displayed automatically

---

### 3.3 Authentication (Bonus but auto-included)

Use BetterAuth.com with:
• Signup page
• Questionnaire about user's skill background
• Store responses in Neon DB
• Use responses to personalize chapters

---

### 3.4 Personalization

Every chapter must include:
• Personalize Content button
• Endpoint call to rewrite blocks based on user profile
• Dynamic rendering of beginner vs intermediate vs advanced sections

---

### 3.5 Urdu Translation

Each chapter must contain a:
• Translate to Urdu button
• Urdu MDX variant generator
• Toggle system between EN and UR

---

### 3.6 Sub-Agents and Reusable Intelligence

Claude Code must generate sub-agents under `/agents/`:

• GlossaryBuilder
• QuizGenerator
• SummaryWriter
• CodeExplainer
• RoboticsMathHelper
• HardwareAdvisor

These agents must be callable during writing or automatically during chapter generation.
